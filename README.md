# Bistroly – Modern Restaurant Website

A modern, elegant and fully responsive restaurant website built with **HTML, CSS and JavaScript**.

## 🌐 Live Demo

**Live Website:**  
https://jasminvansh11.github.io/bistroly-restaurant/

## ✨ Features

- Responsive design for desktop, tablet and mobile
- Modern fine-dining visual style
- Sticky navigation bar
- Smooth scrolling navigation
- Hero section with call-to-action buttons
- About / restaurant story section
- Signature dishes section
- Interactive menu category filters
- Restaurant gallery
- Chef section
- Customer reviews
- Table reservation form with validation
- Contact information and opening hours
- Responsive mobile navigation
- Scroll reveal animations
- Hover effects and smooth UI transitions
- SEO-friendly meta tags
- Open Graph social sharing metadata

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome
- Unsplash Images

## 🎨 Design

Bistroly uses a premium restaurant aesthetic with:

- Dark charcoal backgrounds
- Warm gold accents
- Elegant serif typography
- Clean modern layouts
- High-quality food and restaurant imagery

## 📱 Responsive

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

No build tools or installation are required.
